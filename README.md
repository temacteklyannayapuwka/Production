# Production

Лендинг независимой digital-студии. Адаптивный статический сайт без сборки: достаточно открыть `index.html` в браузере.

## Ветки

- `main` — стабильная версия сайта.
- `feature/admin-panel` — отдельная заготовка будущей административной части.
- `feature/site-features` — дополнительные пользовательские функции.

## Локальный запуск

Откройте `index.html` или используйте любой статический сервер, например `npx serve .`.
