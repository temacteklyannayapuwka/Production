# Stavplus experiments

Статичная экспериментальная версия новостного сайта. Не требует React, сборки или установки зависимостей.

Откройте `index.html` двойным кликом в браузере. Все изображения и стили лежат локально, поэтому страница работает без сети.

## Состав

- `index.html` — главная страница;
- `article.html` — шаблон текстовой статьи;
- `society.html`, `politics.html` и другие — отдельные страницы разделов;
- `styles.css` — адаптивный дизайн;
- `script.js`, `sections.js` — меню и лёгкие интерактивные элементы;
- `assets/` — локальные изображения новостей.
