# Импорт Joomla K2

Команда `import_k2` переносит структурированную JSON-выгрузку Joomla K2 в
Stavplus. Основной сайт не требуется подключать к старой MySQL-базе: экспорт
создаётся в phpMyAdmin и передаётся как файл.

## Что выгрузить

В phpMyAdmin выберите формат **JSON** и таблицы:

- `*_k2_items`;
- `*_k2_categories`;
- `*_k2_tags`;
- `*_k2_tags_xref`.

Отдельно нужен архив каталога `media/k2`. После распаковки команда использует
папки `items/src` и `items/cache`, чтобы сопоставить главное изображение по
формуле `md5("Image" + legacy_id)`.

## Проверка

Сначала примените миграции и выполните полностью обратимую проверку:

```bash
python manage.py migrate
python manage.py import_k2 \
  --source /secure/import/k2-export.json \
  --media-root /secure/import/k2 \
  --dry-run
```

Затем импортируйте первые десять материалов в тестовую базу:

```bash
python manage.py import_k2 \
  --source /secure/import/k2-export.json \
  --media-root /secure/import/k2 \
  --limit 10 \
  --apply
```

После визуальной проверки можно выполнить полный импорт без `--limit`.
Повторный запуск обновляет записи по `legacy_k2_id`, а не создаёт дубли.

JSON-выгрузки, SQL-дампы и архивы изображений не добавляются в Git. Секреты и
пароли команда не принимает и в журнал не выводит.

## Текущая граница

Первая версия переносит категории, теги, связи, новости и главные фотографии.
Импорт K2-галерей, вложений и нестандартных `extra_fields` будет добавлен после
получения реального образца выгрузки, потому что их структура зависит от
установленных расширений старой Joomla.
