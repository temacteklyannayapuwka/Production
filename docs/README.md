# Документация Stavplus

Рабочий Django-код находится в `news/`, `stavplus/`, `templates/` и `static/`.
Эта папка содержит материалы, которые не участвуют в запуске приложения.

- `PRESENTATION.md` — продуктовая презентация;
- `reports/` — исторические и актуальные технические отчёты;
- `prototypes/stavplus-static/` — статический прототип интерфейса;
- `archive/` — устаревшие справочные сниппеты, не импортируемые приложением.

Актуальное инженерное состояние и порядок запуска описаны в корневом `README.md`.

Актуальные отчёты для тимлида:

- [`K2_IMPORT_TECHNICAL_REPORT_2026-09-10.md`](reports/K2_IMPORT_TECHNICAL_REPORT_2026-09-10.md) — логика и результаты переноса Joomla K2;
- [`DESIGN_IMPLEMENTATION_REPORT_2026-09-10.md`](reports/DESIGN_IMPLEMENTATION_REPORT_2026-09-10.md) — реализация Figma-дизайна, адаптивность и UI-аудит.
